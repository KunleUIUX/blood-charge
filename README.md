# Blood Charge

Landing page for Blood Charge, a concept iOS and Android app that helps people in Lagos find a blood donation centre, book a time and see which patient their blood helped.

**Live site:** https://blood-charge.vercel.app
**Case study:** https://www.behance.net/gallery/256830619/Blood-Charge-UX-Design-Case-Study-V2

## What's here

- `index.html`: the whole page, with its CSS and JavaScript inline
- `assets/`: iPhone mockups of the app screens, exported from Figma as WebP
- `favicon.svg`: the app icon

## Details

- Built in plain HTML, CSS and JavaScript, with no framework or build step
- Apple-style motion: staggered hero entrance, phones that spread as you scroll, a word-by-word statement reveal, count-up stats, scroll reveals and parallax, a pinned "Track" scene, and a spring on the final icon
- Responsive from 320 px phones to wide desktops, and respects Reduce Motion
- The App Store and Google Play buttons show a message, because the app is a concept and isn't in the stores

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
